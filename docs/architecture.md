

# Architecture

This project follows a modular, serverless architecture using the Next.js App Router and Supabase.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Database/Auth:** Supabase
- **Styling:** Tailwind CSS

## Data Flow
1. **Frontend:** React Server Components for data fetching.
2. **Backend:** Supabase provides Row Level Security (RLS) to manage data access directly from the client.
